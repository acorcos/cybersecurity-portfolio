\# Endpoint, Cloud Security and Infrastructure Monitoring Operations



Practical experience related to endpoint protection, cloud security, firewall management, infrastructure monitoring, datacenters, network segmentation, backups, resilience, and SQL-based data analysis.



This experience was developed in a distributed hospitality environment and supports my transition into cybersecurity operations.



\## Overview



Security operations experience connected to infrastructure, monitoring, access control, endpoint protection, cloud protection, network security, SQL queries, operational data analysis, and business continuity.



\## Endpoint Protection



Evaluation, implementation, migration, monitoring, and operation of endpoint protection platforms.



Tools and platforms included Trend Micro, Kaspersky, and Check Point Harmony.



\## Cloud Protection



Implementation and operation of cloud protection solutions.



Activities included reviewing suspicious access attempts, unusual login locations, VPN-related access events, suspicious account behaviour, and cloud security alerts.



\## Firewall Management



Configuration and maintenance of policies across approximately 60 Fortinet FortiGate firewalls.



Activities included firewall rules, VPNs, IPsec tunnels, site-to-site connectivity, and secure communication between hotels, headquarters, and datacenters.



\## Network Security



Practical experience with secure connectivity, firewall policies, VPNs, IPsec tunnels, VLANs, network segmentation, and access control.



\## Datacenter Infrastructure



Experience with on-premises and cloud-based datacenter environments.



This included the Picoas datacenter, an on-premises datacenter at headquarters, and a cloud datacenter environment in Covilhã to improve resilience.



\## Hotel Infrastructure Deployment



Participation in the implementation of infrastructure for 21 new hotels.



Scope included firewalls, controllers, servers, switches, Wi-Fi, endpoints, Microsoft 365, Active Directory, VLANs, monitoring, and secure connectivity with central systems.



\## Monitoring with Zabbix



Use of Zabbix to monitor servers, firewalls, network devices, datacenter components, cloud systems, traffic behaviour, sessions, availability, and infrastructure health.



Although Zabbix is not a SIEM, this work helped develop skills in monitoring, alerting, visibility, anomaly detection, investigation, and operational analysis.



\## Dashboards and Alerts



Creation of Zabbix rules, dashboards, and graphs to support security and infrastructure visibility.



Dashboards helped monitor server load, active sessions, traffic behaviour, service availability, site communication, and abnormal behaviour.



\## SQL and Oracle Queries



Practical experience using SQL to create queries and views in Oracle databases.



This experience is relevant to cybersecurity because SQL helps analysts filter, investigate, correlate, and extract information from large datasets, including logs, access records, application data, user activity, and operational events.



\## Backup and Recovery



Experience with backup verification and recovery routines.



This supported resilience against data loss, system failure, ransomware, data corruption, and service outage.



\## Security Documentation



Creation of internal security policies, operational procedures, monitoring documentation, firewall documentation, infrastructure documentation, dashboards, compromised account reports, spam-related reports, and SQL-based operational reports.

\## Reflection



Cybersecurity depends on strong infrastructure foundations.



Security is not only about tools. It also requires visibility, monitoring, documentation, segmentation, controlled access, resilience, data analysis, and continuous improvement.



Working with endpoints, cloud protection, firewalls, datacenters, VPNs, VLANs, monitoring, backups, SQL queries, Oracle views, and distributed hotel infrastructures gave me a practical foundation that is highly relevant to cybersecurity operations.
